# Digibing — Digital Marketing Agency Website

Black & white, scroll-driven one-page site for Digibing (Chennai digital marketing agency), built with vanilla HTML/CSS/JS and a Three.js wireframe/particle background.

## Stack
- Static HTML/CSS/JS (no build step)
- [Three.js](https://threejs.org/) via CDN import map
- IntersectionObserver-based scroll reveals

## Local dev
Just open `index.html` in a browser, or serve it:

```bash
npx serve .
```

## Deploy
Deployed on Vercel as a static site (see `vercel.json`).
